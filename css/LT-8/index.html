CSS Overflow Behavior

Overflow: Visible

This is a long paragraph inside a fixed size box. The purpose of this text is to test how overflow visible works when the content does not fit inside the box.

With overflow visible, the extra content will come outside the box instead of being hidden or scrollable.

This extra paragraph is added to make the content larger than the fixed height.

Overflow: Hidden

This is a long paragraph inside a fixed size box. The purpose of this text is to test how overflow hidden works when the content does not fit inside the box.

With overflow hidden, the extra content will be clipped and will not be visible outside the box.

This extra paragraph is added to make the content larger than the fixed height.

Overflow: Scroll

This is a long paragraph inside a fixed size box. The purpose of this text is to test how overflow scroll works when the content does not fit inside the box.

With overflow scroll, scrollbars will appear so the user can scroll and read the extra content.

This extra paragraph is added to make the content larger than the fixed height.

Overflow: Auto

This is a long paragraph inside a fixed size box. The purpose of this text is to test how overflow auto works when the content does not fit inside the box.

With overflow auto, scrollbars will appear only when the content is larger than the box.

This extra paragraph is added to make the content larger than the fixed height.
